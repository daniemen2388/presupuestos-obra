# Presupuestos de Obra

App web para hacer presupuestos de reformas desde el móvil: lista de precios, partidas, IVA/IRPF, firma del cliente, PDF, envío por WhatsApp y paso a factura.

Los datos se guardan solo en el navegador del móvil (localStorage). Usa «Copia de seguridad» en *Mi empresa* para no perderlos.

Al publicar cambios, sube `VERSION` en `sw.js` para que los móviles reciban la versión nueva.
